# Модули

Каталог содержит вертикальные модули продукта. Каждый модуль — независимый срез
функциональности со своими слоями backend, frontend и данных.

```text
modules/<name>/
├── backend/      # Django-приложение
├── frontend/     # страницы и API-клиенты SPA
├── contracts/    # публичный интерфейс модуля
└── module.yaml   # манифест модуля
```

Правила построения модулей, контракты, формат манифеста и профилей описаны в
`docs/modules.md`. Архитектурное обоснование — `docs/adr/0001-modular-monolith.md`.
Устройство конкретного модуля описано в `docs/architecture-module-<name>.md`
(для ядра — `docs/architecture-module-core.md`).

`_template/` — заготовка для нового модуля.

Текущие модули: `common` (техническая библиотека), `references` (общесистемные
справочники: валюты ISO 4217 и типы курсов), `core` (ядро: пользователи,
аутентификация, роли, оргструктура), `operations` (ядро операционного учёта
кассовых операций) и `operations_standard` (базовый набор кассовых операций).
