# Профили заказчиков

Профиль определяет **комплектацию поставки**: какие модули включены и как они
находят друг друга. Это единственное место, где задаётся «адрес» модуля.

Формат описан в `docs/modules.md`; пример — `example.yaml`.

Файлы вида `profiles/<customer>.yaml` можно держать как для реальных заказчиков,
так и для типовых поставок (например, `profiles/default.yaml`).
